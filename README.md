# دليل الهاتف (نسخة القراءة فقط)

هذا مستودع **عام** يحتوي فقط على ملفات الموقع المبنية (HTML/CSS/JS) لعرضها عبر GitHub Pages:

https://saadbandar.github.io/phone-directory-web/

المصدر الفعلي (الكود، وميزة الدخول والتعديل، وقاعدة البيانات) موجود في مستودع **خاص** منفصل:
`saadbandar/phone-directory`

لا تُعدّل الملفات هنا مباشرة — يُعاد بناؤها ونشرها من المستودع الخاص عند كل تحديث للدليل.
